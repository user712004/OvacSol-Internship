# Student Record & Grade Management System

## Developed By
Eman Javed

## Description

This is a command-line based Student Record & Grade Management System developed in Python.

The system allows users to:

- Add new students
- View all students
- View a single student
- Update student marks
- Delete students
- Automatically calculate Total, Average and Grade
- Save student records permanently using JSON
