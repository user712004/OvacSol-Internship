# Student Result Analysis

## AI Internship Project

### Description

This project analyzes student performance using Python.

The project demonstrates:

- Data Loading
- Data Cleaning
- Data Analysis
- Data Visualization
- Exporting Results

---

## Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib

---

## Project Structure

```
datasets/
charts/
outputs/
notebooks/
```

---

## Features

- Load CSV dataset
- Calculate Total Marks
- Calculate Average Marks
- Assign Grades
- Find Top Students
- Create Bar Charts
- Create Pie Charts
- Create Histograms
- Save Processed Dataset
