# Week 04 - House Price Regression

## Introduction

This project is part of the OvacSol internship and focuses on predicting house prices using machine learning regression techniques.

A real house sales dataset is used to train and evaluate regression models. The project covers data exploration data cleaning exploratory data analysis model training prediction and model performance evaluation.

## Objective

The main objective of this project is to build a machine learning model that can predict house prices based on different housing features.

The project also compares two regression algorithms to determine which model provides better predictions.

## Dataset

The project uses a real house sales dataset containing information about houses and their selling prices.

The dataset includes features such as:

- Number of bedrooms
- Number of bathrooms
- Living area
- Lot area
- Floors
- Waterfront
- View
- Condition
- Grade
- Year built
- Location
- Latitude
- Longitude

The target variable is:

`price`
