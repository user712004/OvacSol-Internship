# Student Record Management System
## Topic Usage

### Variables
Variables are used throughout the project to store student information, marks, menu choices, and filenames.

### Data Types
The project uses strings, integers, floats, dictionaries, and lists.

### Loops
While loops are used for the menu system.
For loops are used to search and display student records.

### Functions
Functions are used to organize the program such as add_student(), update_marks(), delete_student(), and display_students().

### Object-Oriented Programming
A Student class is created with attributes and methods for calculating total, average, and grade.

### File Handling
Student records are stored permanently in students.json using the json module.

### Exception Handling
try-except blocks handle invalid marks and file errors without crashing the program.

### Modules
The project is divided into:
- main.py
- student.py
- file_manager.py
- utils.py

### Virtual Environment
The project runs inside a Python virtual environment.

### Pip
The tabulate package was installed using pip for displaying tables.

## Conclusion

This project demonstrates the use of all Python fundamentals covered during Week 1, including variables, data types, loops, functions, object-oriented programming, file handling, exception handling, modules, virtual environments, and pip.
